# 🍕 Pizza Sales SQL Analysis

A SQL-based data analysis project focused on exploring pizza sales data and extracting business insights using MySQL.

## 📌 Project Overview

This project analyzes pizza sales data using multiple SQL queries across four related tables:

* `pizzas`
* `pizza_types`
* `pizza_orders`
* `order_details`

The analysis is divided into **Basic, Intermediate, and Advanced** SQL queries.

## 🗂️ Analysis Covered

### 🔹 Basic Analysis

* Total number of orders placed
* Total revenue generated from pizza sales
* Highest-priced pizza
* Most common pizza size ordered
* Top 5 most ordered pizza types by quantity

### 🔹 Intermediate Analysis

* Total quantity of pizzas ordered by category
* Distribution of orders by hour of the day
* Category-wise distribution of pizzas
* Average number of pizzas ordered per day
* Top 3 pizza types based on revenue

### 🔹 Advanced Analysis

* Percentage contribution of each pizza type to total revenue
* Cumulative revenue generated over time
* Top 3 pizza types by revenue within each pizza category
